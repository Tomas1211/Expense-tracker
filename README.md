# Expense Tracker

A simple expense tracking app built with HTML, CSS and JavaScript.

## Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- Filter expenses by category
- Calculate total expenses
- Save expenses using Local Storage

## Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage

## What I Practiced

- DOM manipulation
- Event handling
- JavaScript array methods
- Managing application state
- Working with Local Storage
